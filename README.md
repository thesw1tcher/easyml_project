# easyml_project
MIPT Python course project

No-code решение для ML на табличных данных. В GUI пользователь выбирает тип задачи (регрессия, бинарная/многоклассовая классификация), загружает данные для обучения и выбирает целевой столбец, может посмотреть графики распределений данных (подразумевается, что на их основании пользователь сам чистит выбросы через стороннее приложение, например, excel) и heatmap с корреляциями, затем выбирает столбцы, на которых будет обучаться модель и соотношение train/test выборок. Далее приложение делает поиск оптимальных гиперпараметров и обучает модель, рисуя пользователю красивые графики и прогрессбары. Обученную модель можно сохранить и использовать её через это же приложение (делать предикты, вводя данные вручную или по csv).

**Фичи первой итерации:**
Весь проект кроме части с обучением модели (добавление и просмотр таблицы, отрисовка графиков/гистограмм/heatmap)

**Фичи второй итерации:**
Поиск гиперпараметров, обучение, инференс готовой модели

*Используемые библиотеки, не затронутые в курсе* - Streamlit, catboost

**Requirements:** \
Streamlit \
Pandas \
matplotlib \
seaborn \
openpyxl 

**Run**:
```
streamlit run main.py
```
